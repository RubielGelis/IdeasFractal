Este proyecto que se entrega con el codigo fuente tiene

En archivo comprimido encontraran 3 proyectos los cuales son:
1) SaleInfoWS: Este es el proyecto de inicio que crea el servicio web. Este es el servicio que se debe ejecutar y contine el Web.config con la informacion de la conexion a la base de datos y  licencia de ServiceStack.
2) SaleInfoWS.ServiceInterface: Este proyecto contiene la logica de los endpoints usados, y la conexion a la base de datos
3) SaleInfoWS.ServiceModel: Este proyecto contiene el modelado del request y response del servicio, el modelado de la tabla de la base de datos y los tipos de datos usados.

Los anteriores proyectos estan itegrados en una solucon llamada XXXX.sln

Para abrir el proyecto deben tener visual Studio 2017,

En la carpeta Documentos de apoyo encontrana los siguiientes archivos

1) Script bd
2) XML RQ
3) XML RS
4) Ejempl BookReervar
5) DiagramaProceso
6) Ejemplo postmap de servicios
